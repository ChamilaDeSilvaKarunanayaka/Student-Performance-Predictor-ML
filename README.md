# 🎓 Student Performance Predictor (ML Project)

## 📌 Description
This project predicts whether a student will pass or fail based on:
- Study hours
- Attendance

## 🧠 Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## 🚀 Features
- Train ML model
- Save model using joblib
- Predict using user input
- Data visualization

## 📊 Model
- Logistic Regression

## 📷 Example
Input:
Hours: 5
Attendance: 75

Output:
PASS
